Zako Chat V1.0.0 发布说明
===========================

这是 Zako Chat 的首个正式版本，定位为 Windows 10/11 上安静、轻量、接近系统组件体验的 AI 对话工具。

主要亮点
--------
1. 双形态界面
   - 默认快速提问小窗，适合随手提问。
   - 可展开为完整侧边栏，支持历史会话、连续对话和模式切换。

2. 快捷键唤起
   - 默认快捷键为 Ctrl+Shift+Z。
   - 已显示时再次按下会隐藏，隐藏时再次按下会显示快速小窗。

3. WebView2 高级界面
   - 使用 Fluent 风格图标、圆角窗口、柔和阴影和浅色/深色主题。
   - 如果 WebView2 Runtime 不可用，会自动回退到原生 WinForms 轻量界面。

4. 多服务商兼容
   - 内置 OpenAI、Gemini、DeepSeek、智谱、硅基流动、Kimi、OpenRouter、OneAPI/NewAPI 与自定义接口。
   - 支持检测连接延迟并获取可用模型列表。

5. 对话参数与人设
   - 支持流式输出、温度、最大输出长度和 AI 人设提示词。
   - 启动时会修复重复服务商和重复人设配置。

6. 图片与视觉
   - 文字模式下支持上传图片给视觉模型。
   - 图片生成模式支持文本生图预览。
   - 生成图片默认仅作为预览缓存，不自动保存到下载目录；缓存目录可在设置中自定义。

7. 隐私与本地数据
   - API Key 使用 Windows DPAPI 当前用户加密保存。
   - 聊天历史、WebView2 数据和图片预览缓存默认保存在本机 %AppData%\ZakoChat。

发布文件
--------
- ZakoChat-V1.0.0.exe

运行要求
--------
- Windows 10/11
- 推荐安装 Microsoft Edge WebView2 Runtime
- 使用第三方 AI 服务时需要对应服务商的 API Key

已知说明
--------
- 当前版本不包含语音、文件上传、图片编辑、局部重绘或视频生成。
- 不同服务商和中转站的 API 兼容程度不同，如遇到模型列表获取失败，可手动填写 Model ID。
